# Rotation note

Copy this file into the repository as ROTATION.md and fill each section. Name keys by their
id (K-0001), never by their value. Dates, not times of day.

## What leaked

Which secret (its id and what it opens), in which file and commit, since when, and who could
have read it (who can clone the repository).

## Rotated

The old key revoked at the portal (id, date). The new key issued (id) and where it is kept now.

## History cleaned

The command used, the check that proves the old value is gone (the scan of the whole history),
and what everyone with a clone must do now.

## Who was told

The roles told and when: the operations lead who owns the portal account, the data protection
officer. What the portal's access log showed for the old key, if it was checked.
